## Sinclair BASIC semantics — binding correction

The user corrected the earlier mistaken claim that Invaders has broken source.
In Sinclair BASIC, `GO TO` and `GO SUB` for an absent line number enter at the
next higher existing BASIC line. Invaders' line 50 has `GO SUB 70` and the next
existing line is 100, so the jump is valid. Do not add an invented line 70.
`stage/line_targets.py` handles **literal** `GO TO` and `GO SUB` targets in the
compiler's temporary tokenized input, not the preserved tapes. Dynamic
expressions, nested statements, and jumps above the last line need further
semantic review. `stage/basic_listing.py` handles difficult keyword boundaries
in source listings without editing the originals. `stage/prepare_rbc.py` applies
the extensions to the original 102,185-byte fresh-chat checkpoint, fixes a
process UDG check, and handles first-line OPEN placement.

The read-only 60-tape audit is saved in `corpus-line-audit.json`, generated by
`corpus_line_audit.py`, in the experiment directory and in the new checkpoint.
It found 60 `.tzx` inputs, 59 readable by the generic parser and 19 readable
programs with at least one absent literal jump target. The one unparsed input
was `01-minelay.tzx`, where the generic parser reported an invalid BASIC line;
this does **not** prove the original tape is bad. Treat absent jump targets as
valid BASIC where the next-line behavior applies, not as missing source.
