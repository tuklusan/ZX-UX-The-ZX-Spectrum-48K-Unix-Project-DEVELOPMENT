# RBC native game checkpoint — 2026-10-22

The development branch now has an updated compiler, 34 host tests,
and genuine native ZX-UX game captures. All original Sinclair BASIC files
remain unchanged in `src/bonus/60-programs/`.

## Compiler and corpus

- Rebuilt the current experimental compiler from the preserved original
  checkpoint and the live source extensions without an earlier local compiler.
- Recompiled from the original 60 numbered BASIC text files and converted
  original TZX tapes, plus the HELLO test. The strict run compiled 16/121
  inputs, with 105 not compiled. This agrees with the prior baseline. Most
  failures are strict memory checks or unsupported HiSoft language forms.
- Both Galaxians (25) and Invaders (58) compile from original text and
  original TZX-derived tape data into SSX1 binaries.
- The native graphics font remains unchanged across nine saved game frames
  for each original tape-built game. Two inspected sprite definitions per
  game match the original BASIC DATA bytes.

## Native gameplay checks

- Both games start after SPACE on the real ZX-UX kernel model.
- Galaxians enters its gameplay screen, and its ship moves left on z and
  right on x after the idle EAR input is set high in the isolated runner.
  Movement tests save four genuine frames and measured ship columns.
- The native emulator previously returned keyboard-port values 191 when
  idle and 187 while x was down, although the original Galaxians source
  compares to 255 and 251. A runner-only hook now gives those expected
  readings while no cassette pulses are active. The production emulator
  and kernel have not been changed.
- The Galaxians firing key was pressed, but hits, scoring, and longer play
  have not been confirmed. Invaders displays its score and reserve count;
  its enemy glyph byte shapes match the original selected reference, but
  frame positions, colors, and complete gameplay still need review.

## Permanent files

`rbc-native-controls-checkpoint-2026-10-22.zip` contains the prepared
compiler, extension sources, unit tests, SSX1 programs, real ZX-UX PNGs,
full 121-input result data, input hashes, game measurements, and file hashes.
The original BASIC sources and kernel tape stay at their normal GitHub paths.

Next, address the remaining HiSoft errors and memory mapping without
relaxing strict checks. Check key-held firing, state changes, and gameplay
against the original 48K snapshots. A successful boot alone is not a pass.
