COMMANDO JUMP — KEYS AND TIMING

We checked the BASIC source and the real Fuse game screen. A key after GO starts the jump. A second key during the jump can change the result. The source uses INKEY$ rather than a fixed letter. This replay uses Space for both presses.

Run from the repository root:
  sh src/assets/basic-src/original-sinclair-basic-collections/Granada-Publishing/05-commando-jump/BASIC/REPLAY.sh

Fuse SDL 1.6.0 runs at 50% speed. Each wait is real clock time.

  1. Start the original CommandoJump.tap with the 48K ROM and automatic tape load.
  2. Wait 7.0 seconds for the Ready, Steady, GO sequence.
  3. Hold Space for 0.15 seconds, release, then wait 0.15 seconds.
  4. Wait 1.7 seconds; save SCREENSHOTS/01-AFTER-FIRST-KEY.png.
  5. Hold Space again for 0.15 seconds, release, then wait 0.15 seconds.
  6. Wait 4.0 seconds; save SCREENSHOTS/02-AFTER-SECOND-KEY.png.

The tested views show the jumper changing position relative to the wall. The script checks that the pictures differ. The random wait before GO may shift on another run. No complete ten-jump win is claimed.
