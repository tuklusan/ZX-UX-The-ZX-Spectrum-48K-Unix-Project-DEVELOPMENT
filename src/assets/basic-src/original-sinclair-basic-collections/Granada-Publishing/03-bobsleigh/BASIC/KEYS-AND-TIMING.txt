BOBSLEIGH — KEYS AND TIMING

We read the source BASIC and checked the keys in a live Fuse 48K run.

The game first asks for a difficulty from 1 to 5. Enter 1 and press Return for the easiest course. When the track starts, 5 steers left and 8 steers right. The red sled near the top of the track is the player. The code checks a track edge each turn. A crash can end the run at once.

Replay from the repository root:
  sh src/assets/basic-src/original-sinclair-basic-collections/Granada-Publishing/03-bobsleigh/BASIC/REPLAY.sh

The run uses Fuse SDL 1.6.0 at 50% speed. The slower clock leaves room for two moves without turning every trip into a spectacularly short one.

Steps in order, with real clock times:
  1. Load Bobsleigh.tap with the 48K ROM and automatic tape load.
  2. Wait 2.2 seconds for the difficulty prompt.
  3. Hold 1 for 0.08 seconds, release, and wait 0.15 seconds.
  4. Hold Return for 0.08 seconds, release, and wait 0.15 seconds.
  5. Wait 3.5 seconds for the track to appear.
  6. Hold 5 for 0.30 seconds, release, and wait 0.15 seconds.
  7. Save SCREENSHOTS/01-AFTER-LEFT.png.
  8. Hold 8 for 0.30 seconds, release, and wait 0.15 seconds.
  9. Wait 0.4 seconds; save SCREENSHOTS/02-AFTER-RIGHT.png.

The script checks that a red sled appears in both views and that its screen position shifts right by at least three pixels. The track shape can change between runs. Both shots are from the original tape in Fuse, not from a compiled ZX-UX program.
