28-mineblaster--Mineblaster
Original untouched Spectrum 48K snapshot: Mineblaster.z80; original TZX: Mineblaster.tzx. Clean BASIC listing independently decoded directly from original TZX with the existing ROM LLIST converter.

Fly a craft through mines, monitoring lives, mines and time. Actual 48K Fuse screens show the active minefield after both control inputs.
Original listing controls: 7 is tested at line 120, 6 at line 110 for steering.
Two PNGs are actual Fuse 48K emulator captures after live keys 7 and 6, not archive screenshots. A short session does not prove winning or a full playthrough.

Reproduce from repository root: sh src/assets/basic-src/original-sinclair-basic-collections/www.thespectrumshow.net/28-mineblaster--Mineblaster/BASIC/REPLAY.sh. Requires Fuse SDL, Xvfb, Pillow and python-xlib. bin/ remains empty.
