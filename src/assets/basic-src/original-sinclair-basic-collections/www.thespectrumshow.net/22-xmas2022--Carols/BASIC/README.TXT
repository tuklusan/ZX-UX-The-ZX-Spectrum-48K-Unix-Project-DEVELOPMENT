CAROLS — Christmas music for Spectrum 48K

Source: The Spectrum Show Christmas 2022 collection, typed by Paul Jenkinson. The original Z80 snapshot, TAP and TZX are kept unchanged. The BASIC listing was recovered independently from the original TZX with the ZX-UX Spectrum ROM LLIST converter.

The program uses BEEP statements to play Christmas tunes and prints song titles. It is a music demonstration rather than an action game. We loaded the original TZX in Fuse, used RUN, pressed Space at the on-screen start request, and saw the first carol title. The screenshots come from this live session. Audio was disabled during testing, so sound quality, full playback and later songs were not checked. We make no claim of hearing music.

REPLAY.sh uses Fuse SDL, Xvfb, Python 3, Pillow and python-xlib. No native build is included.
