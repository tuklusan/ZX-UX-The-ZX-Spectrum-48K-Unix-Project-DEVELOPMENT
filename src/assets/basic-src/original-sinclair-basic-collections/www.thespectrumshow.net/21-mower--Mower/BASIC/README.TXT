21-mower--Mower
Original untouched Spectrum 48K snapshot: Mower.z80; original archived TZX: Mower.tzx. Clean BAS independently recovered from that TZX with build/tools/zx-tzx2bas.py (125 lines).

The original BASIC screen instructions give Q up, A down, O left, P right. The game tracks oil, mowed lawn, and lives.
Genuine Fuse 48K replay: after Return starts, hold P for 0.7 seconds and Q for 0.5 seconds. The screenshots are emulator pixel captures after each key, showing changed game board and mowed count, not source-archive screenshots.

Run from the repo root: sh src/assets/basic-src/original-sinclair-basic-collections/www.thespectrumshow.net/21-mower--Mower/BASIC/REPLAY.sh. Requires Fuse SDL, Xvfb, python-xlib, Pillow. bin/ stays empty.
