ROBOT CHASE — R. Holmes, Leeds

Source: Spectrum Show, ROBOT-FINAL. The original Z80 snapshot, TAP and TZX are kept byte for byte. The 90-line BASIC listing came from the original TZX using the ZX-UX Spectrum ROM LLIST converter.

The game asks for difficulty 1 (hard) through 10 (easy). The player moves with T, F, G and V, trying to lead chasing robots into mines without stepping on them. We started the original snapshot in Fuse 48K, selected level 10, and pressed F, G, V and T during a live arena. The pictures show the board and later game views, not a victory or complete round. Robots also move on their own, so screen changes alone do not prove each step was a safe move.

The initial snapshot opens in BASIC LIST mode. REPLAY.sh starts RUN and enters the difficulty before saving genuine Fuse screenshots. Requires Fuse SDL, Xvfb, Python 3, Pillow and python-xlib. No native game output is included.
