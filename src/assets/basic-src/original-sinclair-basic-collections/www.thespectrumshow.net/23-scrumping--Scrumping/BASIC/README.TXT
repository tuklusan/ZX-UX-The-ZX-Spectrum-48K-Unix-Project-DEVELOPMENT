23-scrumping--Scrumping
Original Spectrum 48K snapshot: Scrumping.z80; untouched original TZX: Scrumping.tzx. The clean 69-line BAS is independently decoded from that TZX with the repository ROM LLIST tool.

The on-screen instructions say key 1 moves Clive left and key 0 moves him right. The game follows Clive and Sid picking apples. The game requests keyboard input during its introduction; the replay follows those prompts, then presses left and right during the running game.
Two PNGs are genuine Fuse gameplay screens after the indicated keys, showing the dropped-apples count change, not supplied archive screenshots. Fuse is set to 500% to advance the long intro; no full-game completion is claimed.

Replay: sh src/assets/basic-src/original-sinclair-basic-collections/www.thespectrumshow.net/23-scrumping--Scrumping/BASIC/REPLAY.sh from repository root. Requires Fuse SDL, Xvfb, Pillow and python-xlib. bin/ remains empty.
