RADIO POWER - REPLAY KEYS AND TIMING
SANYALnet Labs  |  Spectrum 60  |  Program 13

We recorded these input events during a real FUSE demonstration.
The times are measured from the start of the FUSE runner, in seconds.
They are not timings from the Spectrum's internal clock. That little
computer has enough to do without keeping our stopwatch.

REPRODUCE THE RUN
From this program folder, enter: sh ./REPLAY.sh.
On a Linux host, the package runner uses FUSE, Xvfb, Python 3,
python-xlib, and Pillow. New pictures go to REPLAYS/13-radio-power/ at the
collection root; they do not replace the selected images automatically.

Main capture session: v19-targeted/13-radio-power
Emulator speed: 300%
Recorded ordered script: H:Return:0.5|H:y:0.45|L:AL|L:RADIO|L:SOUTHAMPTON|C:station-view|H:space:0.5

SCRIPT ACTIONS IN PLAIN ENGLISH
  01. Hold Return for 0.5 seconds.
  02. Hold y for 0.45 seconds.
  03. Type AL and press Enter.
  04. Type RADIO and press Enter.
  05. Type SOUTHAMPTON and press Enter.
  06. Save a screen named station-view.
  07. Hold space for 0.5 seconds.
