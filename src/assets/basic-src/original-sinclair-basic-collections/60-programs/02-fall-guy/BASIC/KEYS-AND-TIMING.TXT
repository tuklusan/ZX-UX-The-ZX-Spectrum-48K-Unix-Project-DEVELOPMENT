FALL GUY - REPLAY KEYS AND TIMING
SANYALnet Labs  |  Spectrum 60  |  Program 02

We recorded these input events during a real FUSE demonstration.
The times are measured from the start of the FUSE runner, in seconds.
They are not timings from the Spectrum's internal clock. That little
computer has enough to do without keeping our stopwatch.

REPRODUCE THE RUN
From this program folder, enter: sh ./REPLAY.sh.
On a Linux host, the package runner uses FUSE, Xvfb, Python 3,
python-xlib, and Pillow. New pictures go to REPLAYS/02-fall-guy/ at the
collection root; they do not replace the selected images automatically.

Main capture session: v19-targeted/02-fall-guy
Emulator speed: 300%
Recorded ordered script: H:space:0.5|L:AL|L:BO|W:10|C:main-settled|H:a:0.7|C:after-a

SCRIPT ACTIONS IN PLAIN ENGLISH
  01. Hold space for 0.5 seconds.
  02. Type AL and press Enter.
  03. Type BO and press Enter.
  04. Wait 10 seconds.
  05. Save a screen named main-settled.
  06. Hold a for 0.7 seconds.
  07. Save a screen named after-a.
