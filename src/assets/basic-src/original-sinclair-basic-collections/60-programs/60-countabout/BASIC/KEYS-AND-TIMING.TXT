COUNTABOUT - REPLAY KEYS AND TIMING
SANYALnet Labs  |  Spectrum 60  |  Program 60

We recorded these input events during a real FUSE demonstration.
The times are measured from the start of the FUSE runner, in seconds.
They are not timings from the Spectrum's internal clock. That little
computer has enough to do without keeping our stopwatch.

REPRODUCE THE RUN
From this program folder, enter: sh ./REPLAY.sh.
On a Linux host, the package runner uses FUSE, Xvfb, Python 3,
python-xlib, and Pillow. New pictures go to REPLAYS/60-countabout/ at the
collection root; they do not replace the selected images automatically.

Main capture session: v19-finish/60-countabout
Emulator speed: 250%
Recorded ordered script: K:space|W:2|K:space|W:5|C:counting-task|K:1|C:answer-response

SCRIPT ACTIONS IN PLAIN ENGLISH
  01. Tap space.
  02. Wait 2 seconds.
  03. Tap space.
  04. Wait 5 seconds.
  05. Save a screen named counting-task.
  06. Tap 1.
  07. Save a screen named answer-response.
