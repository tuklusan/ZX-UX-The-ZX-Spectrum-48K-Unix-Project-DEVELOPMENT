ABEN - REPLAY KEYS AND TIMING
SANYALnet Labs  |  Spectrum 60  |  Program 24

We recorded these input events during a real FUSE demonstration.
The times are measured from the start of the FUSE runner, in seconds.
They are not timings from the Spectrum's internal clock. That little
computer has enough to do without keeping our stopwatch.

REPRODUCE THE RUN
From this program folder, enter: sh ./REPLAY.sh.
On a Linux host, the package runner uses FUSE, Xvfb, Python 3,
python-xlib, and Pillow. New pictures go to REPLAYS/24-aben/ at the
collection root; they do not replace the selected images automatically.

Main capture session: v19-targeted/24-aben
Emulator speed: 130%
Recorded ordered script: H:v:0.45|C:main-start|H:z:0.6|C:after-left|H:m:0.5|C:after-fire

SCRIPT ACTIONS IN PLAIN ENGLISH
  01. Hold v for 0.45 seconds.
  02. Save a screen named main-start.
  03. Hold z for 0.6 seconds.
  04. Save a screen named after-left.
  05. Hold m for 0.5 seconds.
  06. Save a screen named after-fire.
