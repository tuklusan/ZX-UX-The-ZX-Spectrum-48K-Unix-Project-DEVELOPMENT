SPACE INVADERS — Spectrum Show, SpaceInv-FINAL

The original collection holds an untouched Z80 snapshot plus TAP and TZX media. We kept those original bytes, and the accompanying 186-line BASIC listing follows the original collection's ROM LLIST export. The saved snapshot first displays BASIC with RUN ready; press Enter to begin. The title then asks for a name, and the game can skip the instructions with N.

The game draws invaders above a gun. The BASIC listing calls 5 left, 8 right, and 0 fire (lines 320, 330, and 350). We ran the original Z80 in Fuse 48K and watched the gun move left, then right, after those keys. Pressing 0 changed the screen. Nothing in this short session proves a full round, a win, or a good score. Space invaders are not known for giving out medals just for showing up.

The genuine Fuse captures are in SCREENSHOTS/. The replay uses the original snapshot, a temporary home directory, a 48K ROM, Xvfb, Pillow, and python-xlib. The original website screenshots are reference only and are not included as fresh play captures. No native SSX output was made.
