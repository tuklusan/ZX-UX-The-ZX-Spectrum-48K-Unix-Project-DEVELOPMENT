EVIL ALIEN — Computer Spacegames, third program

The Spectrum Show collection contains a single-game TAP and TZX for this program. We kept both untouched. The whole 15-program SpaceGames TAP, TZX, and Info.txt are stored with the first game in SpaceGames-01. The 25-line BASIC listing here was decoded directly from this TZX with the Spectrum ROM LLIST converter.

An alien hides at random X, Y, and distance values from 0 to 9. The program lets the player make four three-number attempts. After each miss, it gives directional and distance hints (BASIC lines 130-220). We ran the original tape in Fuse 48K and entered 5,5,5, then 4,4,4. The game gave feedback after both shots and returned to the X prompt. We did not hit the alien or finish a round. The alien has every reason to like that result.

The captured PNGs in SCREENSHOTS/ were saved from the active Fuse session. REPLAY.sh uses Fuse, Xvfb, the 48K ROM, Python 3, Pillow, and python-xlib. No executable game file was built.
