20-spacewaste--SpaceWaste-final

Original 48K snapshot: SpaceWaste-final.z80
Original TZX: SpaceWaste-final.tzx
The .bas was independently decoded from the preserved original TZX using build/tools/zx-tzx2bas.py, without running it.
The archival LLIST reference includes printed 32-column wrapping, so it differs in layout from the clean unwrapped LLIST output.

This is a running space action game. The Spectrum BASIC listing reads 2 and 1 for movement and SPACE to fire (lines 100 and 120).
The screen shows Score and Population. Pressing Return began a running session in a genuine Fuse 48K session.
The two screenshots are genuine captured emulator pixels: first after holding 2 for 0.7 seconds, and second after firing with SPACE for 0.5 seconds.
They show a visual difference after firing; they are not end-to-end gameplay proof.

From the repository root: sh src/bonus/www.thespectrumshow.net/20-spacewaste--SpaceWaste-final/BASIC/REPLAY.sh
The machine must have Fuse SDL, Xvfb, python-xlib and Pillow. bin/ is intentionally empty.
