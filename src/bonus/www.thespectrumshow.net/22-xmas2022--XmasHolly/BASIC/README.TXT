XMAS HOLLY — E. A. Duncan-Dunlop

Source: The Spectrum Show Christmas 2022 collection, typed by Paul Jenkinson. We kept the original Z80 snapshot, TAP and TZX unchanged. The BASIC listing was independently recovered from the original TZX by the existing ZX-UX Spectrum ROM LLIST converter.

This program draws holly leaf shapes. It is a picture-making demo, not a game with player moves. We loaded the original TZX in Fuse 48K, ran it, and recorded the growing green leaves. The live images show an early and later drawing; no keyboard gameplay or sound was claimed. The original snapshot raised a missing Interface 1 ROM message in this Fuse setup, so the replay uses the original tape instead. A small seasonal reminder that software also needs somewhere to live.

REPLAY.sh needs Fuse SDL, Xvfb, Python 3, Pillow and python-xlib. No native build is included.
