INTERGALACTIC GAMES — Computer Spacegames, second program

This single-game TAP and TZX came from the Spectrum Show's 15-program collection. We kept both supplied tapes unchanged. The complete multi-game SpaceGames TAP, TZX, and Info.txt remain in the first program folder, SpaceGames-01. The 23-line BASIC listing here was recovered directly from this single-game TZX through the ROM LLIST converter.

The program asks for a launch angle from 0 to 90 degrees and a launch speed from 0 to 40000. It computes a target from a random satellite height. We loaded this TZX in Fuse 48K, ran BASIC, entered angle 45 and speed 12000, and saw the program report TOO STEEP and TOO FAST. The first attempt returned to an angle prompt. A successful orbit was not shown. Space is big; precision is less optional.

SCREENSHOTS/ has images of this real Fuse run. The replay uses Fuse, Xvfb, the 48K ROM, Python 3, Pillow, and python-xlib. No game executable was made.
