DIVER — SPECTRUM SHOW

We kept the original Diver.z80 snapshot and the source TAP and TZX from the collection. The BASIC listing was exported from the supplied TZX with the existing ZX-UX ROM listing tool. The listing has 116 numbered lines. The snapshot runs in Fuse 48K with the cave field visible. The program source assigns 5, 8, 6, and 7 to movement. We sent these four keys and saved the changing screen after each key. The screen changed, but we could not isolate each change from the background motion. No treasure pickup, escape, or completed round is claimed.

REPLAY.sh starts the original snapshot and saves four live Fuse views. It needs Fuse SDL, Xvfb, Python 3, Pillow, python-xlib and the 48K ROM. No native build is included.
