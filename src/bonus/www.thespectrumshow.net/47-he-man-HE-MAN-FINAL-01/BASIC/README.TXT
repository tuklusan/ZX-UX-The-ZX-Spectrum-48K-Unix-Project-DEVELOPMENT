HE-MAN — Robert Pearmain

We kept the original TZX and TAP bytes from the Spectrum Show collection. The original tape contains a Spectrum BASIC loader plus a separate 768-byte machine-code block. Both parts are needed: BASIC line 5 loads the CODE block into memory. The 98 numbered BASIC lines were decoded directly from the TZX with the ZX-UX ROM listing tool. No replacement code was made.

Fuse 48K loaded the complete original TZX. The screen invited us to press any key to begin the quest. We pressed SPACE and saw the status and enemy screen. Two more SPACE presses produced changed scenes, including a wound message and a new status report. This is real input-driven play, but the game picks its own battle results. We did not defeat the enemies or rescue the princess; that is still on HE-MAN's rather crowded calendar.

The original instructions say to press any key to start. BASIC line 295 waits for a key between battle results; these are the recorded player inputs. No directional control keys were verified. Screenshots came directly from Fuse, not the archive reference images. No native output was built.
