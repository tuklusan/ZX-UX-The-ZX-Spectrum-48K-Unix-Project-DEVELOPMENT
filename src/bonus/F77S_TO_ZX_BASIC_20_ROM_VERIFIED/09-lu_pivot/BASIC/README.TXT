LU_PIVOT — F77S FORTRAN demonstration converted to ZX Spectrum 48K BASIC

Original media: LU_PIVOT.tzx, unchanged bytes from the supplied F77S archive.
Source SHA-256: 08d3d91d2872a41fc38021ded63ca6c2111a3f1635f502ed2b2c3d84ae24d0f6
Listing: LU_PIVOT.bas, decoded independently from the original TZX with
ZX-UX build/tools/zx-tzx2bas.py (Sinclair 48K ROM LLIST spacing).

Start: Fuse auto-loads the TZX. The program prints its mathematical
result and stops. This is a numerical demonstration, not an action game.
Controls: none during the demonstrated run. See KEYS-AND-TIMING.txt.
Replay: sh BASIC/REPLAY.sh; requires Fuse, Xvfb and Python Pillow.
SCREENSHOTS/01-RESULT.png is a genuine frame from Fuse SDL 1.6.0,
run against this TZX and the repository 48K ROM, captured at STOP.
The archive's independent numerical checks are not a compiler test.
No native RBC SSX has been generated. The bin/ directory is intentionally
empty for a future build and cannot be represented by Git until populated.
