AT THE CONTROLS
We reached the Dogfight flight field and captured its response to key input. The planes were not obliged to hold position for the camera.

TO START
Attach 43-dogfight.tzx to a 48K ZX Spectrum or FUSE session. Type LOAD "" and
press Enter. When loading is complete, type RUN and press Enter. The tape
has no automatic start, so the program waits for that second command.

We can repeat the recorded demonstration on a supported Linux computer.
From this folder, enter: sh ./REPLAY.sh. The runner writes fresh captures
to the collection's REPLAYS/43-dogfight/ directory. For exact key events and their
times, open KEYS-AND-TIMING.TXT.

WHAT THE SCREENS SHOW
We kept the settled introduction, working display, or visible response
where that frame was useful. No screenshot of typed loading commands is
part of this set. Some programs need fewer than three images.

These captures demonstrate a short working session, not every possible
path through the program. Exact frames can vary with input timing or the
program's choices. The listing and tape data are unchanged from v21.
