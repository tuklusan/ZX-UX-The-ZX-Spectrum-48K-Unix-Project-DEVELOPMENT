AT THE CONTROLS
We reached the bridge with the participants in place. A keypress changed the live display. The bridge looked much more useful once everyone had arrived.

TO START
Attach 03-tug-of-war.tzx to a 48K ZX Spectrum or FUSE session. Type LOAD "" and
press Enter. When loading is complete, type RUN and press Enter. The tape
has no automatic start, so the program waits for that second command.

We can repeat the recorded demonstration on a supported Linux computer.
From this folder, enter: sh ./REPLAY.sh. The runner writes fresh captures
to the collection's REPLAYS/03-tug-of-war/ directory. For exact key events and their
times, open KEYS-AND-TIMING.TXT.
