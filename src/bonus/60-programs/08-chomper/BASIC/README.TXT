Book reference: pages 39-43

AT THE CONTROLS
We moved Chomper among the pellets and saw the score increase. The pellets kept disappearing. The score had an explanation.

TO START
Attach 08-chomper.tzx to a 48K ZX Spectrum or FUSE session. Type LOAD "" and
press Enter. When loading is complete, type RUN and press Enter. The tape
has no automatic start, so the program waits for that second command.

We can repeat the recorded demonstration on a supported Linux computer.
From this folder, enter: sh ./REPLAY.sh. The runner writes fresh captures
to the collection's REPLAYS/08-chomper/ directory. For exact key events and their
times, open KEYS-AND-TIMING.TXT.
