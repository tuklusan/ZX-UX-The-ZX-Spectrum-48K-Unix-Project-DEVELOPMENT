AT THE CONTROLS
We reached the terrain display and recorded alien movement after key input. The visitors showed no interest in standing still for the camera.

TO START
Attach 11-defend.tzx to a 48K ZX Spectrum or FUSE session. Type LOAD "" and
press Enter. When loading is complete, type RUN and press Enter. The tape
has no automatic start, so the program waits for that second command.

We can repeat the recorded demonstration on a supported Linux computer.
From this folder, enter: sh ./REPLAY.sh. The runner writes fresh captures
to the collection's REPLAYS/11-defend/ directory. For exact key events and their
times, open KEYS-AND-TIMING.TXT.
