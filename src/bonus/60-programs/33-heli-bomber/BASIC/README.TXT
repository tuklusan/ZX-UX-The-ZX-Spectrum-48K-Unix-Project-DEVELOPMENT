AT THE CONTROLS
We reached the Heli Bomber field and captured the change after controls were used. The helicopter had no reason to pose for a still photograph.

TO START
Attach 33-heli-bomber.tzx to a 48K ZX Spectrum or FUSE session. Type LOAD "" and
press Enter. When loading is complete, type RUN and press Enter. The tape
has no automatic start, so the program waits for that second command.

We can repeat the recorded demonstration on a supported Linux computer.
From this folder, enter: sh ./REPLAY.sh. The runner writes fresh captures
to the collection's REPLAYS/33-heli-bomber/ directory. For exact key events and their
times, open KEYS-AND-TIMING.TXT.
