Capture the Quark — Granada Publishing

Preserved original 48K TAP byte-for-byte: CaptureTheQuark.tap. CaptureTheQuark.tzx wraps precisely the original TAP flagged blocks in standard TZX blocks, with untouched payloads and valid original XOR checksums. The 215-line CaptureTheQuark.bas was freshly decoded from the wrapped original using build/tools/zx-tzx2bas.py (ROM LLIST). The archive also holds separately named Quarks material; this directory contains the CaptureTheQuark original only.

Play: move a selected piece diagonally using 5 (left) or 8 (right); other keys switch selected pieces; r asks whether to resign. The program alternates player and quark moves. Genuine Fuse screenshots were captured after two real directional keyboard moves from the original TAP. They show changed positions, not just a loader or menu. Run sh BASIC/REPLAY.sh from this game directory, or invoke it from anywhere using its full path. No native binary was created; bin/ stays empty.
