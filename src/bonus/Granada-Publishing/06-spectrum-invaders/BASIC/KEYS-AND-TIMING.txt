SPECTRUM INVADERS — KEYS AND TIMING

We read the original BASIC and checked the launcher in Fuse 48K.

  5: steer the launcher left.
  8: steer the launcher right.
  7: fire a missile.

The game starts on tape load and draws its alien rows. The replay uses Fuse SDL 1.6.0 at 50% speed. Each wait below is real clock time.

From the repository root, run:
  sh src/bonus/Granada-Publishing/06-spectrum-invaders/BASIC/REPLAY.sh

  1. Load the original SpectrumInvaders.tap with the 48K ROM.
  2. Wait 2.5 seconds for the first game screen.
  3. Hold 5 for 0.50 seconds; release and wait 0.15 seconds.
  4. Wait 0.4 seconds; save 01-AFTER-LEFT.png.
  5. Hold 8 for 0.50 seconds; release and wait 0.15 seconds.
  6. Wait 0.4 seconds; save 02-AFTER-RIGHT.png.
  7. Hold 7 for 0.50 seconds; release and wait 0.15 seconds.
  8. Wait 0.4 seconds; save 03-AFTER-FIRE.png.

The script checks that the green launcher moved right and that the screen changed after firing. We inspected the pictures as game screens, not title cards. This does not claim a full win.
