MIGHTY MISSILE — KEYS AND TIMING

We checked the original BASIC source and a real Fuse 48K run.

The source uses 5 to move the missile position left and 8 to move it right. Both keys also start a shot. The game begins on tape load, with a shield and moving attacker. There is no separate start choice in this tape.

Run from the repository root:
  sh src/bonus/Granada-Publishing/08-mighty-missile/BASIC/REPLAY.sh

Fuse SDL 1.6.0 runs at 50% speed. All waits refer to real clock time.

  1. Open MightyMissile.tap with the 48K ROM and automatic tape load.
  2. Wait 5.0 seconds for the live attack screen.
  3. Hold 5 for 0.55 seconds, release, and wait 0.15 seconds.
  4. Wait 0.35 seconds; save 01-AFTER-LEFT.png.
  5. Hold 8 for 0.55 seconds, release, and wait 0.15 seconds.
  6. Wait 0.35 seconds; save 02-AFTER-RIGHT.png.
  7. Wait 2.0 seconds; save 03-LATER-GAME.png.

The replay checks that the game changes after input and continues to change. We inspected the screens for a player craft and attackers. No complete win is claimed.
