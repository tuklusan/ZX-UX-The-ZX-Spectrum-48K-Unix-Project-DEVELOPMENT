# Third-party components supplied with the ZX-UX SDK

The SDK tools (`rcc`, `ras`, `rld`, `rtap`, `rvm`) require Python 3.11 or later.

- **z80-python 0.4.0** — Z80 processor used by RVM and the compiler's
  Sinclair ROM floating-point calculations. MIT licence:
  https://github.com/alewman/z80-python
  The required MIT license text is included at `py/z80_python/LICENSE`.
- **Sinclair ZX Spectrum 48K ROM** — 16K system ROM used for Spectrum
  emulation and compiler floating-point calculations. The ROM's copyright
  remains with its rights holder; the distributed ROM must retain its
  original copyright messages and is not for separate sale. Distribution
  notice: https://github.com/z00m128/zxs-rom/blob/master/LICENSE.md

The 4-by-8 font is ZX-UX project code, not a third-party package.
