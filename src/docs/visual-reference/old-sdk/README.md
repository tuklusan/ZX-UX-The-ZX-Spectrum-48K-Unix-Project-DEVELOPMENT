# Historical C48 SDK screenshot references

These 48 PNG files are historical C48 SDK output screenshots, not captures from the current ZX-UX v1 kernel. They are retained as traceable comparison inputs only.

The 24 `demos/` and six `examples/` PNGs came from the owner's abandoned repository, `tuklusan/ZX-UX-old-abandoned`, at `v1/dist/media/P11.pre-release/sdk/reference-png/`. The 14 `games/` and four `apps/` PNGs came from the owner's checked historical `OLD-ZX-UX-C48-SDK.zip`, at `ZX-UX-C48-SDK/repo/docs/images/`. Their checked source bytes and Git blob hashes were preserved; they have not been recreated, painted, or edited.

`demos/ocean.png` is the authentic historical SDK screenshot for the ocean graphics demo, headed `OCEAN GRID / THREE WAVE FIELD`. Its Git blob identity is `02e14428becf2fa68ab6eafea2a7a7435c8d3395`.

Do not substitute any of these for native `.scr` captures. Pixel equality with a new SDK output does not establish native execution, equal input timing, or an identical kernel state. Native old-kernel reference captures are a different historical dataset and are not included here.
