AT THE CONTROLS
We reached the finished two-player maze. Pressing A changed a player position. A few lonely sprites would have been a rather poor map.

TO START
Attach 02-fall-guy.tzx to a 48K ZX Spectrum or FUSE session. Type LOAD "" and
press Enter. When loading is complete, type RUN and press Enter. The tape
has no automatic start, so the program waits for that second command.

We can repeat the recorded demonstration on a supported Linux computer.
From this folder, enter: sh ./REPLAY.sh. The runner writes fresh captures
to the collection's REPLAYS/02-fall-guy/ directory. For exact key events and their
times, open KEYS-AND-TIMING.TXT.
