SPACE TRAFFIC
SANYALnet Labs  |  Spectrum 60  |  Program 30 of 60
Book reference: pages 152-155

AT THE CONTROLS
We reached the Space Traffic field, moved, and fired a laser. Space traffic turned out to need controls too.

TO START
Attach 30-space-traffic.tzx to a 48K ZX Spectrum or FUSE session. Type LOAD "" and
press Enter. When loading is complete, type RUN and press Enter. The tape
has no automatic start, so the program waits for that second command.

We can repeat the recorded demonstration on a supported Linux computer.
From this folder, enter: sh ./REPLAY.sh. The runner writes fresh captures
to the collection's REPLAYS/30-space-traffic/ directory. For exact key events and their
times, open KEYS-AND-TIMING.TXT.

FILES IN THIS FOLDER
  30-space-traffic.tzx - the non-auto-run Spectrum tape.
  30-space-traffic.bas - the decoded BASIC source (data block: 4523 bytes).
  README.TXT - this guide and the book page reference.
  KEYS-AND-TIMING.TXT - the actual input and capture log.
  REPLAY.sh - the Linux FUSE demonstration script.
  REPLAY-INTRO.sh - optional separate introduction run.
  SCREENSHOTS/ - selected genuine FUSE captures:
  SCREENSHOTS/01-INTRO.png - intro; captured at 14.975 s.
  SCREENSHOTS/02-FLIGHT.png - flight; captured at 16.717 s.

WHAT THE SCREENS SHOW
We kept the settled introduction, working display, or visible response
where that frame was useful. No screenshot of typed loading commands is
part of this set. Some programs need fewer than three images.

These captures demonstrate a short working session, not every possible
path through the program. Exact frames can vary with input timing or the
program's choices. The listing and tape data are unchanged from v21.
