# ZX-UX v1 release guide

Run `python3 tools/release.py` from the repository root. The build writes
`release/dist/`, including both separate C48 screenshot galleries at
`release/dist/screenshots/rvm/index.html` and
`release/dist/screenshots/fuse/index.html`.

See `docs/REPRODUCIBLE-V1-RELEASE.md` for the required tools and outputs.
The command neither pushes to GitHub nor creates a tag.
