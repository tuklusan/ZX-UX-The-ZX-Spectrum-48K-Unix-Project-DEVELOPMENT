# Historical C48 SDK screenshot references

These PNG files are historical SDK output screenshots from the owner's abandoned ZX-UX repository, not captures from the current ZX-UX v1 kernel. They are retained as traceable comparison inputs only.

Original location: `tuklusan/ZX-UX-old-abandoned`, under `v1/dist/media/P11.pre-release/sdk/reference-png/`. Each image was checked against the historical Git blob identity before transfer. Do not substitute these for native `.scr` captures.

`demos/ocean.png` is the authentic historical C48 SDK screenshot for the ocean graphics demo, headed `OCEAN GRID / THREE WAVE FIELD`. It displays a cyan wireframe ocean on a blue Spectrum screen, with a circular graphic and mathematical text. Its exact historical Git blob is `02e14428becf2fa68ab6eafea2a7a7435c8d3395`. This screenshot is a visual reference, not a current ZX-UX v1 native emulator capture. Game and app PNGs from the checked old SDK archive are still pending transfer.

Pixel equality with the new SDK's rendered frame does not establish native execution, equal input timing, or an identical kernel state.
